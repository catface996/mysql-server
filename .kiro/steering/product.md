# MySQL 服务器

MySQL 是由 Oracle 开发的开源关系型数据库管理系统 (RDBMS)。此仓库包含 MySQL 服务器源代码，包括：

- **MySQL 服务器** - 核心数据库服务器 (mysqld)
- **客户端工具** - 命令行工具，如 mysql、mysqldump、mysqladmin
- **存储引擎** - InnoDB、MyISAM 和其他可插拔存储引擎
- **MySQL Router** - 用于数据库连接路由的轻量级中间件
- **测试套件** - 综合测试框架 (mysql-test)

## 主要特性
- ACID 兼容事务
- 多版本并发控制 (MVCC)
- 复制和集群支持
- 可插拔存储引擎架构
- SQL 标准兼容性
- 用于监控的性能模式
- JSON 数据类型支持
- 全文搜索功能
